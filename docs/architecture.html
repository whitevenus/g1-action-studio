先从 cli.py 开始

点击任意模块框，查看它做什么、调用什么，以及哪些数据会进入或离开它。灰色箭头用于主调用或处理关系；图并非把每个框当成一个独立进程。

建议学习顺序

  1. cli.py：命令如何分发。
  2. record.py → author.py：实测状态如何成为草稿。
  3. live_replay.py → replay.py：如何生成目标序列。
  4. executor.py → replay_sdk.py：反馈检查与真实命令。
  5. teach.py：示教侧为何跟随测量。
  6. transition.py → collision.py：两段动作怎样绕开机体。

先分清三种数据

反馈：机器人实际测到的 q / dq，经 rt/lowstate 返回。

目标：规划器希望机器人到达的关节角度，保存在 frames 中。

命令：把目标角度、增益和权重填进 LowCmd，计算 CRC 后调用 publisher.Write()。

两条容易混淆的边界

transition 的碰撞检查只用于离线过渡。当前 replay --execute 尚未使用它，也不接受过渡输出格式。

内存模拟和真实 SDK 报文审计都不操作真机。报告 completed 表示执行流程完成，实际动作与控制交接仍需现场确认。
