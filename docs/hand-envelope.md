# 未知手型下的完整活动范围检查

仅手臂控制不接收手指反馈，但不能删除安装在手腕上的实体手。当前仅支持内置 Dex3-1 模型，不能将其当作其他型号或实际设备尺寸的自动确认。

## 已验证的设计调整

2026-10-16，首版链长球在真实 MuJoCo 模型中与同侧手腕发生永久的假碰撞；利用关节限位收紧球体仍不能通过。用户明确同意改用更细的保守包络，继续覆盖完整活动范围，不扩大安装排除，不使用固定手型假设。

最终实现保留原始碰撞网格，把“所有允许手型”表达为关节区间内网格位置的并集，并通过自适应区间划分证明距离。它不是有限姿态采样，也没有为通过测试而裁剪手指限位。

## 距离下界

对一对碰撞几何，收集会影响其位置的所有未知手指祖先关节。每个关节的位移半径上界包括：几何局部偏移、几何包围半径，以及到该关节的全部下游固定连杆长度。

设某个关节区间的中点为 `q_mid`、半宽为 `h_j`，两几何对关节 `j` 的半径上界之和为 `R_j`，则距离的保守下界为：

```text
lower = distance(q_mid) - Σ(R_j × h_j) - numerical_margin
```

依据是转动弧长不超过半径乘转角，几何之间的距离变化不超过两几何位移之和。所有关节都在区间内时，该不等式仍成立。

1. 从完整关节限位区间开始。
2. 下界大于所需净空，则整个区间通过。
3. 若某个中点已不满足净空，整个候选手臂姿态拒绝。
4. 否则按位移上界最大的关节二分，检查两个子区间。
5. 深度达到 24 或累计访问 4096 个节点仍未证明时，返回根区间的保守下界；结果不足以证明净空便拒绝。

数值余量为 `0.0001 m`，报告算法名为 `joint_interval_mesh_union_v1`。报告的距离是保守下界，可能贴近请求的净空，并不是精确的全手型最小距离。

## 碰撞对与帧间运动

保持掌部以及躯干、双臂和对侧手的检查。同一只手内部的包络重叠不作为外部碰撞；同侧手与手腕仍检查，原有直接安装关系不扩展。

受控关节为 14 个并不减少实体碰撞集合。帧间检查仍使用完整下游链长来界定手部几何在手臂运动中的最大位移，在每个中间手臂姿态查询全部未知手型的距离下界。

同侧手与腕的相对几何只依赖该侧腕角，因此模型实例可复用此类距离查询。缓存不跨模型实例、不对腕角取整，净空阈值也属于缓存键。其他几何关系不使用此缓存。

## 验证范围

Linux 的 `test_arm7_flow` 验证非零手臂运动、手部与手腕检查、身体碰撞拒绝以及完整 CLI 流程。随机手型对原始网格的检查只是辅助回归，覆盖保证来自区间下界。

规划仍在发送控制命令之前或示教工作线程中执行，不在 DDS 回调内运行。检查通过只证明内置模型与固定身体姿态下的几何条件，不代表实物、动态环境、外部障碍或控制交接已验收。
