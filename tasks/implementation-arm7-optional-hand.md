## 几何方案调整

首版链长球及限位收紧球都会与同侧手腕产生假碰撞。用户在本对话中明确批准更细的保守包络，继续覆盖完整活动范围且不扩大排除。

最终算法为 `joint_interval_mesh_union_v1`：保留原碰撞网格，通过完整手指关节区间的距离下界证明净空。界限为中点网格距离减去两几何链长位移上界之和，再保留数值余量；不能证明时二分，预算不足拒绝。

该变化已同步 SPEC 与手部包络说明；不是缩小手指限位、删除手部几何或改成固定手型。

## 原有基线问题

开始时已有两项测试与已提交的1秒反馈阈值不一致：恰好1秒旧的时间戳被当作过期。当前测试改用超过阈值的反馈，不改变运行阈值和包含边界的判断。

CLI 回放原有位置参数绑定错误已修正为关键字参数，新增命令入口回归保证输出路径、侧别、速度及执行开关不移位。
